# Silvio César Stecca — Portfólio

Página de portfólio pessoal, construída em HTML/CSS puro (sem frameworks), com foco em apresentar trajetória profissional, competências técnicas e formação de forma direta e objetiva.

**🔗 Site publicado:** [rsstecca.github.io](https://rsstecca.github.io)

## Sobre

Especialista ADVPL/TLPP com mais de 12 anos de experiência no ecossistema TOTVS Protheus (v11/v12), atuando hoje como Tech Lead. O site reúne:

- Perfil profissional e áreas de especialização
- Competências técnicas por categoria (ERP Protheus, banco de dados, módulos funcionais, desenvolvimento web, fiscal, ferramentas)
- Linha do tempo com a trajetória profissional completa
- Formação acadêmica e idiomas
- Informações de contato

## Funcionalidades

- **Download em PDF** — botão que aciona a impressão nativa do navegador (`window.print()`) com uma folha de estilo dedicada (`@media print`) para gerar um PDF limpo do currículo, sem depender de bibliotecas externas.
- **Design responsivo** — layout adaptado para desktop e mobile.
- **Zero dependências de build** — HTML e CSS em um único arquivo (`index.html`), fontes carregadas via Google Fonts (Inter + JetBrains Mono).

## Stack

- HTML5 + CSS3 (custom properties / variáveis CSS)
- Sem frameworks, sem bundler — publicado direto via GitHub Pages

## Rodando localmente

Não há build. Basta clonar e abrir o arquivo no navegador:

```bash
git clone https://github.com/rsstecca/rsstecca.github.io.git
cd rsstecca.github.io
open index.html   # ou: xdg-open index.html
```
